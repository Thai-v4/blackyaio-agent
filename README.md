# blackyaio-agent

Profil d'agent [UCP](https://ucp.dev) de **blackyaio**, un outil personnel de surveillance de stock.

- `profile.json` : version UCP et capacités déclarées (recherche et lecture du catalogue uniquement).
- Aucune donnée personnelle, aucun secret, aucune clé.
- L'outil ne crée ni panier ni commande côté serveur : l'acheteur finit toujours lui-même, dans son navigateur.
